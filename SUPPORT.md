# Support

Use [GitHub Issues](https://github.com/boaz-hwang/codex-doctor/issues) for bugs, compatibility reports, and feature requests.

Include:

- Codex CLI version (`codex --version`).
- Node.js version (`node --version`).
- Operating system.
- Whether the failure affects live account limits, active-session fields, or both.
- Redacted terminal output or `--json` output when safe.

Do not post authentication tokens, `auth.json`, session transcripts, thread IDs, email addresses, or other private account data. For a sensitive report, email [hkc7180@gmail.com](mailto:hkc7180@gmail.com) with the minimum information needed to reproduce the issue.
